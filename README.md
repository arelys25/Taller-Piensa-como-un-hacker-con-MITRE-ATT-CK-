# Think Like a Hacker: Learn to Identify Attacks with MITRE ATT&CK 🛡️

At **CUTonalá InnovaTech 2026**, I delivered the workshop **"Think Like a Hacker: Learn to Identify Attacks with MITRE ATT&CK"**.

Over 3 hours, we looked at how to use this framework to understand what an attacker does at each stage and how to recognize those techniques. Teaching it helped me understand the topic even better.

## Contents

| File | Description |
|---|---|
| [`Presentacion_MITRE_ATTACK.pdf`](Presentacion_MITRE_ATTACK.pdf) | Workshop slides (in Spanish) |
| [`actividades/Actividad1_Rompe_el_Caso.pdf`](actividades/Actividad1_Rompe_el_Caso.pdf) | **Activity 1 — Crack the Case:** in teams, read an intrusion scenario and identify, in order, the ATT&CK tactics it involves |
| [`actividades/Actividad2_Cazadores_de_Amenazas.pdf`](actividades/Actividad2_Cazadores_de_Amenazas.pdf) | **Activity 2 — Threat Hunters:** research a real threat group on attack.mitre.org and build its profile in ATT&CK Navigator |

## Topics

1. Who is MITRE and why does it exist?
2. The knowledge ecosystem: CVE, CAPEC, CWE, ATT&CK, ATLAS, and D3FEND
3. What is ATT&CK? Tactics, techniques, and procedures (TTPs)
4. Cyber Kill Chain vs. ATT&CK
5. Anatomy of the matrix: the 15 tactics
6. Groups, software, and campaigns (Sandworm Team / BlackEnergy / Ukraine 2015 case)
7. Ecosystem tools: ATT&CK Navigator, CALDERA, Atomic Red Team, and Attack Flow Builder
